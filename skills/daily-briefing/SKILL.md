# Daily briefing

Gather with tools: task_list (active + finished since last briefing), reminder list (today/overdue), memory_search for current projects.
Format: (1) Needs you today (decisions, overdue, deadlines) (2) In progress (3) Finished since last time (4) One suggested focus. Max ~150 words, in Friday's voice, no fluff. If nothing is pending, say so in one line.
