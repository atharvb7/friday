# Report writing

- Lead with the answer: a 3-5 bullet executive summary.
- Then sections ordered by importance to the reader, each with a one-line takeaway heading.
- Use tables for comparisons. Keep paragraphs under 5 lines. No filler.
- Every factual claim traceable: cite sources or say "inferred".
- End with "Risks / unknowns" and "Recommended next steps".
- Save as `report.md` (and `report.html` if a shareable page is requested) in the working directory.
