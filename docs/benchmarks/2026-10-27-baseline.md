# Friday brain benchmark: baseline (27 Oct 2026)

The first full benchmark of Friday's brain, taken before the rest of development. Rerun it after each big change
and compare against this file.

## How it was measured

- **Harness:** `scripts/bench/brain-bench.mjs` runs the real brain (system prompt, personality, tool loading,
  guards, model router) on a scratch data directory. External services are stubbed with fixed data: inbox, web
  pages, laptop online, image/document/research/code tools. The same test always sees the same world.
- **Tests:** 39 cases in total.
  - 25 everyday cases (`scripts/bench/cases.mjs`): tools 13, multi-step 2, honesty 3, safety 2, reasoning 3, persona 2.
  - 14 hard cases (`scripts/bench/cases-hard.mjs`): several tools or constraints per request, existing state,
    traps hidden in tool data.
- **Grading:** automatic graders check the actual tool calls and arguments, what was staged for approval, and the
  reply text. Every case runs once, so a single result can flip between runs.
- **Setups:**
  - "OLD Friday" is the code on the server today (commit 83baf95): all 73 tools on every call.
  - "NEW Friday" is commits 0eea1f4 and 6e21ced: tool loading, the stop-retrying guard, the new router and Gemini.
    It uses the default chains, so the everyday model is Nemotron 3.5 Super VL.
  - The other rows are NEW Friday pinned to a single model, with no fallback.

## What this shows

1. **The suite is near its ceiling for Nemotron-class models.** Lightning (index 13) scores the same as Super (26)
   here. Friday's design does a lot of the work: tool rules, guards and approvals. The suite catches regressions
   but does not rank strong models well. Harder tests are needed before the post-development comparison:
   long multi-step jobs, real browsing, document quality, sales-email quality judged against the profile's
   reference email.
2. **The optimisation kept quality and cut cost.**
   - Input tokens fell from 1,844k to 722k (-61%).
   - Total time fell from 671s to 504s (-25%).
   - The score rose from 37 to 38 out of 39, because the retry loop is fixed.
3. **Free access to the stronger models is not reliable.** Step 5 is accurate when it answers, but it timed out
   on a third of requests at about 100s each. MiniMax was mostly rate-limited. Gemini Flash allows 20 requests a
   day. Reliability, not capability, is the blocker today.
4. **Ultra is the most accurate single model (100% when answered) but the slowest**: median 14.5s against 8.8s for
   NEW Friday's chain.
5. **Bugs found:**
   - (a) There is no way to edit a reminder. Friday creates a second one and says "Changed". Fix: add
     reminder_update, or cancel the old one.
   - (b) Lightning sometimes skips staging a WhatsApp message.
   - (c) Weaker models get "3pm their time" (time zones) wrong.

## Not covered yet

- Gemini 3.8 and 3.6 Flash: the free quota (20/day) is smaller than one run needs.
- GLM-5.3 and DeepSeek V4.1 Flash: unreachable on NVIDIA.
- Voice, laptop computer-use, real Gmail and the prospecting pipeline: these need live services.
- Each case ran once; no repeats, so there is no variance estimate.
